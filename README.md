# SkyproNodeJs

📖 О приложении:
skypro-node-js – серверное бэкенд приложение для управления библиотечной системой. 
Разработано на Node.js с использованием Express.js и MongoDB. 
Позволяет отслеживать книги, читателей и их взаимодействие в цифровой библиотеке. 
Показывает понимание RESTful API принципов, работу с базами данных, обработку ошибок и написание тестов. 

🛠️ Технологии:
Node.js – серверная платформа
Express.js – веб-фреймворк для роутинга и middleware
MongoDB – NoSQL база данных
Docker – автоматизация развёртывания
Mongoose – ODM для работы с MongoDB
Nodemon – автоматическая перезагрузка при разработке
Postman – тестирование API

📱 Основные функции: 
• Управление пользователями (читателями):
1.	Получение списка всех зарегистрированных читателей
2.	Поиск читателя по уникальному ID
3.	Регистрация новых читателей
4.	Обновление данных существующих читателей
5.	Удаление аккаунта читателя
• Управление книгами:
1.	Получение каталога всех доступных книг в библиотеке
2.	Поиск книги по ID с детальной информацией
3.	Добавление новых книг в библиотечный фонд
4.	Обновление информации о существующих книгах
5.	Списание книг из библиотечного фонда
6.	Отслеживание статуса книги (доступна/выдана)
• Библиотечные операции:
1.	Выдача книги читателю
2.	Возврат книги в библиотеку

🏗️ API Endpoints:
*GET*
/visitors	                                          получить список всех посетителей
/books	                                            получить список всех книг
/visitors/:visitor_id	                              просмотреть данные посетителя по его id
/books/:book_id	                                    просмотреть данные книги по её id

*POST*
/visitors/new-member	                              добавление нового посетителя
/books/new-item	                                    добавление новой книги

*PATCH*
modification/visitors/:visitor_id	                  изменить данные посетителя по его id
modification/books/:book_id	                        изменить данные книги по её id
/visitors/:visitor_id/book-to-visitor/:book_id	    выдать книгу
/visitors/:visitor_id/visitor-book-back/:book_id  	вернуть книгу

*DELETE*
removal/visitors/:visitor_id	                      удаление посетителя из списков библиотеки
removal/books/:book_id	                            удаление книги из списков библиотеки
